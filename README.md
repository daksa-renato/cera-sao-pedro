# O tempo ganha forma

Protótipo local em React + Vite para explorar uma narrativa de fabricação controlada pela rolagem.

- `npm install`
- `npm run dev`
- `npm run build`

O vídeo em `public/video/modelagem.mp4` acompanha a rolagem. A versão local foi codificada sem áudio e com quadros-chave frequentes para facilitar avanços e retornos. O primeiro quadro é usado como capa.
